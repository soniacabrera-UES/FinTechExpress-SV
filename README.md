# FinTech Express SV - Entorno de Pruebas de Seguridad

Aplicativo web deliberadamente vulnerable desarrollado para la materia de **Auditoría de Sistemas (AUS-115)** de la Universidad de El Salvador (UES).

## ⚠️ DERECHO Y AVISO LEGAL
Este código contiene vulnerabilidades de seguridad intencionales (OWASP Top 10) con fines estrictamente educacionales. Su despliegue y análisis debe realizarse exclusivamente dentro de los entornos autorizados por la cátedra, en cumplimiento con la **Ley Especial contra Delitos Informáticos y Conexos de El Salvador**.
